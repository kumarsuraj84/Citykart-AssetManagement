## 4. Decisions taken where the brief was open

1. **"Received Into"** is the label of the manual PO's delivery stock room (the brief said "Deliver To"); the owner's locked words win, with the helper "The Stock Room the goods arrive at".
2. **"Also link the other N registrations" starts unticked** — a person confirms every link (never auto-merge); suggestions are buttons, never preselected. The Item suggestion is also not preselected: **Use suggestion** is one click.
3. **Remember default = `suggested_scope`** (when the line has the Article / product name it needs); sent as `remember: true` + `map_scope: null`, an explicit `map_scope` only when the person picked another reach.
4. **Changing a matched line's Item** defaults to "this code only" for everyone but the head-office admin (server refuses a re-point by others); the refusal sentence also offers the button.
5. **Not tracked default reach** = the same suggested reach; Department / Section / Division listed only for `is_head_office_admin`.
6. **Company in the ERP review is read-only** (the ERP decides it; the server refuses another). A select appears only if a draft has no company.
7. **Header opens by itself** when the ERP gave no Cost Centre (or no company), so the only missing header field is never hidden.
8. **Vendor panel also offers "Or link to another vendor…"** (any active vendor), for suppliers without a suggestion.
9. **Manual PO**: tax defaults to 18 (as Add Set); description / brand / warranty are sent only when changed from the Item's (the server applies the defaults, so "Laptop Dell Latitude 5440" still forms when brand / model are typed); blank lines/sets are dropped on save so "Line N" in a server sentence matches the screen; the footer total includes tax.
10. **"PO created: …" on the PO page** is handed over in memory (`po-flash.ts`), shown once; a reload simply shows the PO.
11. **Inbox "+ New Item"** opens the shared Item dialog (capabilities, type-of-asset list, serial rule) and then resolves with `item_id`, instead of sending `create_item` — one Item form in the app.
12. **Inbox NAME reach** sends one entry per distinct product name; a code that has no product name falls back to CODE.
13. **ERP vendors dialog**: "Add one vendor and link all N" only while no registration of that PAN is linked (otherwise "Link all N to <that vendor>"), so one supplier is never split into two vendors; pages of 25 groups (client-side over the full list the server already returns).
14. **ERP Mapping keeps its name** in the nav (existing tests, bookmarks, e2e); "Advanced mapping rules for the rare cases" is its line and page wording, with an ERP Inbox button and note.
15. **Home row order**: ERP Inbox rows before "Finish setting up" (daily decisions before one-time setup).
