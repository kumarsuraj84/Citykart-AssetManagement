## Not possible here / limits

- **Native Windows execution was not possible**: the development host has no Python and production must not be
  touched. Windows behaviour was EMULATED on Linux: `PureWindowsPath` / `ntpath.isreserved` (Python's own Windows
  path rules), exact decoded paths sent straight to the ASGI app, and monkeypatched filesystem functions proving no
  filesystem call happens before the lexical refusal. Windows-only effects (an SMB connection on stat of a UNC path,
  NTFS junctions, real 8.3 aliases, device files) were not executed; they are refused before any filesystem call, so
  they cannot be reached. The Windows probes stay with WP-R / the post-deploy check, and must not be run on
  production before this change is deployed.
- The N2 launcher test can only see launchers inside the repository; the live `shared\run_ckam_web.ps1` on the
  server is EXT-38. The Dockerfile test needs the Dockerfile next to the tests (a checkout, or copied into the
  container as done for this run); inside a plain image it skips, and the PID-1 command-line test covers the image.

## User-visible behaviour changes

1. An unknown `/api/...` address (any method) answers a JSON 404 "This API address does not exist…" instead of the
   web page (single-port production) or a bare "Not Found" / 405.
2. A server started WITHOUT `ENVIRONMENT_NAME` now counts as production (hidden API docs; refuses a weak
   JWT_SECRET). Docker dev/UAT/sec stacks set the name explicitly and are unaffected; production must keep
   `ENVIRONMENT_NAME=production` and a strong secret (EXT-39).
3. The start-up refusal text is longer and names both rules.
4. New password refusals: look-alike spellings of one's own name, and passwords that are only a simple run plus a
   short number.
5. The brand / vendor Excel import refuses rows whose name already exists (or repeats within the file), with a plain
   row message; the preview shows them as errors.
6. New optional settings `PO_SOURCE_SSLMODE` / `PO_SOURCE_SSLROOTCERT` (default = unchanged behaviour); an invalid
   mode stops the start.
